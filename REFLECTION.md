
Working on the BrewMetrics BI Dashboard was a valuable learning experience because it helped me understand how raw transactional data can be converted into meaningful business insights using Power BI. One of the most important parts of the project was transforming the flat sales dataset into a star schema using `Fact_Sales`, `Dim_Date`, `Dim_City`, and `Dim_Product`. This improved my understanding of data modeling and relationships.

I also gained practical experience with DAX by creating measures such as Total Sales, Total Quantity, Month-over-Month Growth, Running Total Sales, Item Sales Rank, Average Selling Price, and percentage-based comparison measures. I learned that DAX formulas need to be tested carefully because the result depends on the data model and filter context.

GitHub Copilot was useful for generating initial DAX suggestions, especially for time intelligence, ranking, and running-total calculations. However, I learned that AI-generated code should not be accepted without checking it against the actual table names, columns, relationships, and project requirements. I made corrections where necessary, particularly with `ALLSELECTED` and the Average Selling Price calculation.

Creating the dashboard also improved my skills in visual design, KPI development, slicers, drill-downs, conditional formatting, colors, and typography. Using Git and GitHub helped me understand version control and organized project development.

Overall, this project improved my practical knowledge of  **Power BI, DAX, data modeling, dashboard design, GitHub, and responsible use of AI-assisted development** .
